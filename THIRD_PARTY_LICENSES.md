## Qt / PySide6 — **LGPLv3** (important)

PlotaViz's GUI uses [PySide6](https://doc.qt.io/qtforpython/), the official Python bindings for
Qt, licensed under the **GNU Lesser General Public License version 3**.

Distributing an application bundle (`.app`, AppImage) that embeds Qt carries LGPL obligations.
PlotaViz handles them as follows:

- **Qt is dynamically linked.** PyInstaller ships Qt as separate shared libraries inside the
  bundle rather than statically linking it, which preserves the user's right to relink the
  application against a modified Qt.
- **Qt sources.** The corresponding source for the Qt version bundled in a release is available
  from [download.qt.io](https://download.qt.io/archive/qt/) and from the
  [Qt for Python repository](https://code.qt.io/cgit/pyside/pyside-setup.git/). The release notes
  for each PlotaViz release state the exact PySide6/Qt version bundled.
- **Relinking.** Because Qt libraries live as separate `.so`/`.dylib` files inside the bundle, a
  user may replace them with their own build of the same Qt version.
- The full LGPLv3 text is distributed with PySide6 and is reproduced by Qt at
  <https://www.gnu.org/licenses/lgpl-3.0.html>.

Qt is a trademark of The Qt Company Ltd. PlotaViz is not affiliated with or endorsed by
The Qt Company.

### QtWebEngine

The interactive chart view uses QtWebEngine, which embeds **Chromium**. Chromium is distributed
under a BSD-style license with additional components under a range of licenses; the complete set
is available in the browser at `chrome://credits` in a Chromium build, and in the Qt source
distribution under `qtwebengine/src/3rdparty`. QtWebEngine itself is LGPLv3 under the same terms
as the rest of Qt.
